Canonical look for Findter Custom Filter & Search mockups. Tokens come from the Polarised Settings work (NgocDungNguyen/Settings). Placement comes from Merged, Filter, Custom Design, and the Shopify admin chrome used in older replicas.

6. Components

Buttons

Height 32px, radius 8px, pad 6×16, weight 550. Primary uses inset Polar shadow, not a flat black fill.

Toggle

44×24 track, 18×18 thumb, 3px inset, on = #303030. Not 34×19, not Shopify green.

Tabs

Underline 2px --fill. No pill tabs unless they are Shopify admin sub-nav already in an older page.

Banners & badges

Info banner — #e8f4fe, text #003d9c. Use for “applies to product card only”.

7. Spacing & radius

Page pad 24px. Card pad 16px. Control gap 8px. Section gap 16px. Radius: badge/checkbox 4px, card/input/button 8px, modal 12px. Focus: 0 0 0 3px rgba(0,91,211,.2).

8. Icons

16×16 Polar SVG, fill currentColor. No Font Awesome on new pages. Logo mark is Fd on #303030, 28×28, radius 6px — not a red TD square.
