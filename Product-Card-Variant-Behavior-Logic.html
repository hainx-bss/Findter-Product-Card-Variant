Mục tiêu
- Merchant cấu hình variant options hiển thị trên product card (Collection / Search Result) mà không làm vỡ grid, đặc biệt trên mobile.
- Admin Preview phải mô phỏng đúng presentation của storefront: display type, thứ tự option, overflow, swatch shape, click action.
- Hệ thống hỗ trợ option name custom (Finish, Pack Size, Pattern…), không hard-code Color / Size / Material.
- Availability và combination phải lấy từ variant data thật của Shopify, không từ scenario giả trong admin preview.
- Save chỉ persist configuration của app. Không mutate product / variant data trên Shopify.		Mockup: Settings.html

Phạm vi áp dụng
- Surface: product card trên Collection page và Search Result page.
- Variant selection trên card phải tương thích với PDP Variant Picker và Quick Add.
- Không áp dụng các setting này cho Variant Picker trên Product Detail Page.

Nguồn dữ liệu (source of truth)
- Option list, option values, variant id, availability, media mapping đều import từ Shopify product/variant.
- Màn hình này không cho merchant tạo option mới hoặc tạo value mới.
- Mỗi Shopify source option là một Variant Set độc lập (ví dụ Color, Size, Material, Finish, Pack Size).
- Unique key của value là option value id / variant id, không dùng display label.
- Một source option chỉ được map vào đúng một Variant Set. Cấm map trùng.		Không hard-code Color/Size/Material
Cấu trúc dữ liệu tối thiểu của một Variant Set
- sourceOptionId / sourceOptionName
- enabled = true/false
- presentationOrder (thứ tự trên card; chỉ ảnh hưởng presentation, không đổi Shopify option position)
- displayType = Image swatch | Color swatch | Text button | Dropdown | Not shown
- swatchShape = Circle | Square | Rounded (chỉ áp dụng Image/Color swatch)
- imageSource = option value image | variant featured image | manual image (chỉ Image swatch)
- clickBehavior = Update image and link | Open Quick Add | Open PDP
- overflowMode = Show +N more (single line) | Horizontal scroll
- unavailableStyle = Grey out | Hide | Cross out		Click / overflow / unavailable đang là setting dùng chung cho mọi option trên card (theo mockup hiện tại).
Feature toggle: Enable variant options
- Default an toàn: OFF. Khi OFF, product card không render bất kỳ option row nào.
- Khi ON, chỉ render các option đang enabled, có source hợp lệ, và có visible value count > 0.
- Bật toggle trên product không có variant option: không render row rỗng.
- Tắt/bật feature không được làm mất cấu hình đã lưu và không được đổi variant data Shopify.		ADM-01
Imported option list
- Hiển thị đúng các option có thật trong variant data của catalog (ví dụ Color, Size, Material, Finish, Pack Size).
- Hiện số values detected trên từng row.
- Option bị xóa khỏi product sau sync: chuyển Needs attention hoặc ẩn, không giữ configuration rỗng trên storefront.
- Data sync lỗi: giữ last known configuration; không render option không còn source.		ADM-02 / LOG-01 / VAL-02
Enable từng option + priority

- Drag & drop đổi presentationOrder. Thứ tự này dùng cho card và cho việc ưu tiên khi không gian hẹp.
- Drag không hợp lệ: giữ thứ tự cũ, không mất cấu hình.
- Priority không đổi Shopify option position.		ADM-03 / ADM-04
Display type
- Merchant chọn: Image swatch, Color swatch, Text button, Dropdown, Not shown.
- Default là suggestion theo dữ liệu (ảnh/màu có sẵn), merchant được override.
- Không suy luận cứng theo tên option (không ép Color = swatch, Size = text).
- Thiếu ảnh/màu: fallback Text button hoặc value label. Không render thumbnail rỗng.
- Display type = Not shown tương đương disable option khỏi card.
- Đổi display type chỉ đổi presentation, không reset enabled / order / các option khác.		ADM-05
Swatch shape
- Circle / Square / Rounded.
- Chỉ áp dụng Color swatch và Image swatch. Text button và Dropdown không bị ảnh hưởng.

- Swatch thumbnail lấy theo source đã chọn.
- Ảnh product chính trên card chỉ đổi khi resolve được variant/combination hợp lệ.
- Image swatch là presentation của value, không phải product media chính.		ADM-07 / LOG-03
Click behavior và variant resolution
- Update image and link: chỉ chạy khi app resolve được combination/variant khớp toàn bộ selected options.
- Open Quick Add: chỉ khi resolve được variant; nếu không → fallback Open PDP.
- Open PDP: luôn mở product page, không yêu cầu resolve xong trên card.
- Selected state lưu theo source option id/name, ví dụ {Finish: Matte, Pack Size: 2 pack}.
- Khách được chọn option theo thứ tự bất kỳ. Availability của option còn lại tính lại theo selection hiện tại (dynamic, không static).
- Không match combination: giữ nguyên card, disable/grey/hide value xung đột, không đổi ảnh/giá/link sai variant.
- Value không hợp lệ: bỏ selection đó, giữ trạng thái trước.
- Khi combination hợp lệ: cập nhật ảnh, price, compare-at price và product link. Thiếu media → product featured image.		ADM-08 / VAR-01..04
Overflow
- Show +N more (single line): đo width thật của card; render các value vừa chỗ; luôn chừa chỗ cho badge +N; không wrap; không cắt giữa text — ẩn nguyên chip.
- Không dùng số lượng value cố định cho mọi viewport.
- Horizontal scroll: nowrap + overflow-x; hiện đủ value; không hiện +N; không làm tăng chiều cao card.
- Mục tiêu: tránh mobile card nhảy dòng / breakout, và lỗi XL / Wool bị cắt.		ADM-09 / LOG-04 / LOG-05 / RES-01 / RES-02
Unavailable handling
- Grey out / Hide / Cross out áp dụng cho value không mua được, tính từ variant data thật sau khi có selected options hiện tại.
- Admin không nhập combination thủ công và preview không phải source of truth cho availability.
- Khi selection đổi, availability các option còn lại được tính lại.
- Nếu setting = Hide và mọi value của một option đều unavailable: ẩn cả option row, không để khung rỗng.
- Sold-out toàn product: giữ sold-out state của theme.		ADM-10 / AVA-01 / AVA-02

Validation khi Save
- VAL-01 Duplicate mapping: chặn Save nếu cùng source option nằm ở hai set. Không silently overwrite.
- VAL-02 Missing source: Needs attention; không render config rỗng; fallback tắt set lỗi, giữ set còn hợp lệ.

- VAL-04 Save feedback: hiện saved state nếu valid; error summary nếu invalid. Network lỗi: giữ draft local, cho retry.		Must

- EXC-04 Theme/app khác: không chồng event handler, không duplicate control; namespace DOM/event; fallback PDP/Quick Add nếu card hook không tương thích.		EXC-01 Must / EXC-02 Should / EXC-03 Should / EXC-04 Must

FeatureTab/SectionUI RequirementNote
1. Mục tiêu
Xây dựng UI và behavior của variant options trên product card storefront (Collection / Search) khi merchant đã bật Enable variant options trong Findter Settings.
Khách chọn option trên card để preview variant (ảnh/giá/link) hoặc đi tiếp Quick Add / PDP, mà không phá layout card.
2. Phạm vi áp dụng
- Collection page product grid và Search Result product card.
- Hỗ trợ display type: Image swatch, Color swatch, Text button, Dropdown.
- Không thay Variant Picker trên PDP. Option không show trên card vẫn chọn được trên PDP.
- Compatible với Quick Add nếu resolve được variant.
3. Cấu trúc hiển thị trên card
Thứ tự từ trên xuống:
- Product media + badge (Sale…)
- Product name, vendor, price
- Các option row theo presentationOrder của option đang enabled
- CTA Add to cart / Quick add (theo theme/app, không do setting này vẽ lại toàn bộ card)
Mỗi option row:
- Label option (COLOR, SIZE, MATERIAL…)
- Value controls theo display type
Không render row nếu: feature off, option disabled, không có source, visible value count = 0, hoặc Hide hết value unavailable.		EXC-01
4. Logic selected options và combination
- State theo option id, không hard-code color/size.
- Chỉ update image, price, compare-at, product link khi match variant chứa đủ selected values.
- Không match: giữ card, đánh dấu value xung đột theo unavailable style.
- Availability là dynamic theo selection hiện tại.
- Selection invalid: reset option cuối hoặc yêu cầu chọn lại, không add nhầm variant.
- Unique key = option value id. Duplicate label vẫn resolve đúng id.		VAR-01..04
5. UI & behavior theo Display type
5.1 Image swatch
- Thumbnail value; selected ring rõ; hover không tự đổi option khác.
- Ảnh card chỉ đổi sau khi combination hợp lệ.
5.2 Color swatch
- Hình màu theo mapping; cùng shape Circle/Square/Rounded.
5.3 Text button
- Chip label; one-line overflow.
5.4 Dropdown
- Dùng khi nhiều value / merchant chọn; không phá chiều cao card quá mức (Should theo display type list).
Click action (dùng chung):
- Update image and link
- Open Quick Add (fallback PDP nếu không resolve)
- Open product page
6. Overflow
- +N single line: đo width card thật, chừa badge, ẩn nguyên chip, không wrap, không cắt giữa text (fix XL/Wool).
- Horizontal scroll: đủ value, không +N, không tăng height card.
- Desktop grid nhiều cột và mobile đều dùng cùng rule, chỉ khác container width.		LOG-04 / LOG-05 / RES-02
7. Unavailable values
- Grey out / Hide / Cross out theo admin.
- Tính từ imported variant data, không từ preview giả.
- Hide hết value → ẩn cả option row.
- Product sold out: theo theme sold-out, không vẽ control gây hiểu nhầm.		AVA-01 / AVA-02
8. Responsive
- Desktop: mọi option enabled, không wrap ngoài overflow.
- Mobile: card theo container; option one-line hoặc scroll; không breakout viewport; không nhảy height vì wrap.
- Không có Mobile maximum riêng.
9. Compatibility
- Không render đúp nếu theme/native Shopify swatch đã có trên card. Respect warning admin đã chốt.
- Namespace DOM/event, không chồng handler theme/filter app khác.
- Card hook không tương thích → fallback PDP / Quick Add, không silent fail khiến khách chọn sai variant.		VAL-03 / EXC-04
10. Những gì không xuất hiện trên storefront card
- Drag handle, admin toggle, Needs attention, mapping hex editor, Save.
- Empty wrapper / empty option frame.
- Option đang Not shown / disabled / không match product.
