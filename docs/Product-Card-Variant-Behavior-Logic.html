- Custom option / metafield trên card là presentation; không tạo SKU mới.
3. Cấu trúc hiển thị — mode option picker
Thứ tự từ trên xuống:
- Product media + badge (Sale…)
- Product name, vendor, price
- Option rows theo presentationOrder của option đang shown
- CTA Add to cart / Quick add (theme/app)
Mỗi option row: label option (COLOR…) + value controls theo display type.
Không render row nếu: Enable custom off, variant-as-product on, option not shown, không có source, visible value count = 0, hoặc Hide hết value unavailable.		EXC-01
4. Cấu trúc hiển thị — mode variant as product
- Một card cho mỗi variant (không gộp về 1 product).
- Name có thể kèm variant title (· Navy).
- Ảnh / giá theo đúng variant đó.
- Không render option picker trên card.
- Product không có variant: 1 card, không nhân bản giả.		ADM-11 / EXC-05
5. Logic selected options và combination (mode picker)
- State theo option id, không hard-code color/size.
- Chỉ update image, price, compare-at, product link khi match variant chứa đủ selected product_option values.
- Không match: giữ card, đánh dấu value xung đột theo unavailable style.
- Availability dynamic theo selection hiện tại.
- Custom/metafield click không invent variant.
- Unique key = value id. Duplicate label vẫn resolve đúng id.		VAR-01..04
6. UI & behavior theo Display type
6.1 Image swatch: thumbnail; selected ring; hover không tự đổi option khác; ảnh card đổi sau combination hợp lệ.
6.2 Color swatch: hình màu; shape Circle/Square/Rounded.
6.3 Text button: chip label; one-line overflow.
Click action card-level:
- Update image and link
- Open Quick Add (fallback PDP nếu không resolve)
- Open product page
7. Overflow
- +N single line: đo width card thật, chừa badge, ẩn nguyên chip, không wrap, không cắt giữa text (fix XL/Wool).
- Horizontal scroll: đủ value, không +N, không tăng height card.
- Desktop nhiều cột và mobile cùng rule, khác container width.		LOG-04 / LOG-05 / RES-02
8. Unavailable values
- Grey out / Hide / Cross out theo admin.
- Tính từ imported variant data, không từ preview giả.
- Hide hết value → ẩn cả option row.
- Product sold out: theo theme sold-out.		AVA-01 / AVA-02
9. Responsive
- Desktop: mọi option shown, không wrap ngoài overflow.
- Mobile: card theo container; option one-line hoặc scroll; không breakout viewport.
- Không có Mobile maximum riêng.
- Variant-as-product: grid nhiều card hơn; card vẫn cùng template, không option row.
10. Compatibility
- Không render đúp nếu theme/native Shopify swatch đã có trên card.
- Namespace DOM/event, không chồng handler theme/filter app khác.
- Card hook không tương thích → fallback PDP / Quick Add, không silent fail.		VAL-03 / EXC-04
11. Những gì không xuất hiện trên storefront card
- Drag handle, admin toggle, Include all / Exclude all, Add variant, Needs attention, mapping hex editor, Save.
- Empty wrapper / empty option frame.
- Option đang Not shown / disabled / không match product.
- Option picker khi variant-as-product ON hoặc Enable custom OFF.
